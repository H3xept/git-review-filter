GitFilter

Filters for GitHub pull request “Files changed” pages. Changes save automatically.

Presets

Each preset hides a group of files on every repository.

Global rules

One rule per line, applied to every repository. Last matching line wins.
*.spec.* matches a file name anywhere · src/gen/** matches from the repository root · docs/ matches a directory · !keep.spec.ts shows a file again · re:^api/.*\.json$ is a regular expression · # starts a comment.

    Jev low-interest suggestions

    Jev is TypeSafe’s decision model. When you click “Analyze” on a pull request, GitFilter asks Jev to classify each changed file and suggests hiding the ones that need little review attention. Nothing is hidden until you accept a suggestion.

    What is sent to TypeSafe: for each analyzed file, the pull request title, the file path, its change type and line counts, and up to 3,000 characters of its diff. Requests go from this browser directly to api.typesafe.ai with your API key and are billed to your TypeSafe account.
